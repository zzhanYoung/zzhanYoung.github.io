# Zihan Yang's homepage

[View the public site](https://zzhanyoung.github.io)

This is a zero-build static site. Edit `index.html` and `stylesheet.css` directly; keep `CNAME` and all existing fragment identifiers stable.

## Adding a publication

1. Add the entry to the correct year group, newest first.
2. Link the publication title to its canonical project, publisher, or arXiv page.
3. Give every short resource link a paper-specific `aria-label`.
4. For media, provide an explicit `href`, descriptive alt text and caption, intrinsic `width` and `height`, `loading="lazy"`, and `decoding="async"`.
5. Use `is-highlighted` only for the three selected first- or equal-author works; use factual tags such as `New`, `Oral presentation`, or an award independently.
6. Update the page description, structured data, or social card only when the site's overall positioning changes.
